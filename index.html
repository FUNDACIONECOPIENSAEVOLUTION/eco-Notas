🔐 Copias y traslado del PC al celular

Esta versión almacena los datos únicamente en este navegador, NO en un servidor. Para calificar desde otro dispositivo, exporta la copia e impórtala allí. Al terminar, trae la copia actualizada de vuelta al PC antes de seguir editando. No uses varios dispositivos en paralelo: aún no hay sincronización central.

Los listados contienen datos personales de menores. Conserva las copias privadas, no subas exámenes ni listados reales a repositorios públicos, y protege los dispositivos. El repositorio solo debe contener el programa, nunca sus notas.

☁️ Sincronización privada con Java

Conecta el programa web al servidor Java de Eco-Notas. Una vez conectado, las notas y los exámenes se guardarán en el servidor al cambiarse y podrán descargarse desde el computador o el celular.

Primero instala y protege el servidor Java detrás de HTTPS. No pongas contraseñas ni datos de alumnos en GitHub. La aplicación web no almacena la contraseña: deberás iniciar sesión de nuevo al recargar la página. Si dos dispositivos editan a la vez, se detiene la sincronización para evitar perder notas.

Sin conexión al servicio Java. Los datos permanecen únicamente en este navegador.

El servidor Java solo atiende a un docente por instancia en esta versión inicial. Para varios docentes se necesitará autenticación individual y permisos por institución.
